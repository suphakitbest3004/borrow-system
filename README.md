# ระบบสารสนเทศบริการยืม-คืนวัสดุและครุภัณฑ์พร้อมการแจ้งเตือน
### วิทยาลัยการอาชีพหนองหาน จังหวัดอุดรธานี

ระบบสารสนเทศบริการยืม-คืนวัสดุและครุภัณฑ์ พัฒนาด้วยภาษา **Python (Flask + SQLAlchemy + SQLite/MySQL compatible)** ออกแบบด้วยสไตล์ **มินิมอล (Minimalist)** เรียบหรู สะอาดตา ใช้งานง่าย รองรับการทำงานทั้งบนคอมพิวเตอร์และสมาร์ทโฟน ตรงตามขอบเขตและโครงสร้างฐานข้อมูลของเอกสารโครงงาน 100%

## 🌟 ฟังก์ชันการทำงานหลักตามความต้องการ

1. **ผู้ใช้หรือผู้สมัครเข้ามายืม สามารถดูข้อมูลส่วนตัวของตนเองได้ (Requirement 1)**
   - หน้า **ข้อมูลส่วนตัว / โปรไฟล์ (`/profile`)** แสดงข้อมูลครบถ้วน: รหัสนักศึกษา/เลขบัตรประชาชน, ชื่อ-นามสกุล, แผนกวิชา, อีเมล, เบอร์โทรศัพท์, และ LINE User ID
   - สรุปสถิติส่วนตัว (กำลังยืมอยู่กี่รายการ, เกินกำหนดคืนกี่รายการ, คำขอทั้งหมด, คืนสำเร็จแล้วกี่รายการ)
   - ตารางแสดงรายการที่กำลังยืมอยู่ พร้อมวันครบกำหนดส่งคืนและการแจ้งเตือนค่าปรับ
   - ตารางติดตามสถานะคำขอยืม (รอพิจารณา / อนุมัติแล้ว / ไม่อนุมัติพร้อมเหตุผล)
   - ประวัติการส่งคืนย้อนหลังและลิงก์ดูใบเสร็จค่าปรับ
   - ระบบแก้ไขข้อมูลส่วนตัวและเปลี่ยนรหัสผ่านได้ด้วยตนเอง

2. **เจ้าหน้าที่สามารถกดอนุมัติได้ และมีข้อความแจ้งเตือน (Requirement 2)**
   - หน้า **ศูนย์จัดการคำขอยืม (`/admin/requests`)** แยกแท็บ: รอพิจารณา (Pending), อนุมัติแล้ว (Approved), ไม่อนุมัติ (Rejected)
   - ปุ่ม **"อนุมัติ" (Approve)** เพียง 1 คลิก:
     - หักลดยอดสต็อกคงเหลืออัตโนมัติ
     - เปลี่ยนสถานะคำขอเป็น 'approved'
     - บันทึกรหัสเจ้าหน้าที่ผู้อนุมัติ
     - **ส่งข้อความแจ้งเตือนอัตโนมัติ (LINE Messaging API / Email / In-app Notification)** ไปยังผู้ยืมทันที
   - ปุ่ม **"ปฏิเสธ" (Reject)** พร้อมระบุเหตุผลเพื่อส่งแจ้งเตือนไปยังผู้ยืม
   - มีหน้าบันทึกประวัติการส่งแจ้งเตือน (`/admin/notification-logs`) เพื่อตรวจสอบการส่งข้อความ

3. **ระบบสามารถ เพิ่ม ลบ แก้ไข ข้อมูลผู้ใช้, วัสดุ ครุภัณฑ์, หมวดหมู่ใหม่ และข้อมูลอื่น (Requirement 3)**
   - **จัดการข้อมูลผู้ใช้ (`/admin/users`)**: เพิ่ม, ลบ, แก้ไข, ค้นหา, กำหนดบทบาทสิทธิ์ (นักศึกษา, อาจารย์, เจ้าหน้าที่, ผู้ดูแลระบบ)
   - **จัดการวัสดุและครุภัณฑ์ (`/admin/equipment`)**: เพิ่ม, ลบ, แก้ไข, ตรวจสอบจำนวนคงเหลือ, ค้นหาตามหมวดหมู่
   - **หน้าเพิ่มวัสดุและครุภัณฑ์ (`/admin/equipment/new`)**: สามารถเพิ่มรายการพร้อมกันได้หลายแถว (Batch Add) พร้อมปุ่ม **"💾 บันทึกทั้งหมด"** บันทึกทุกรายการในคราวเดียว
   - **จัดการประเภท/หมวดหมู่ (`/admin/categories`)**: เพิ่มประเภทใหม่ได้ทันที จำแนกเป็น "ครุภัณฑ์ (คงทนถาวร)" หรือ "วัสดุ (ใช้หมดไป)"
   - **จัดการสถานที่จัดเก็บ (`/admin/locations`)**: กำหนดห้องจัดเก็บ อาคาร ตู้ล็อกเกอร์
   - **จัดการการรับคืนและค่าปรับ (`/admin/returns`)**: คำนวณค่าปรับคืนล่าช้าอัตโนมัติวันละ 100 บาทตามระเบียบ พร้อมออกใบเสร็จรับเงิน
   - **แดชบอร์ดและรายงาน (`/admin/dashboard`)**: สรุปสถิติคลังพัสดุและพิมพ์รายงาน

4. **สามารถเพิ่มรูปภาพอุปกรณ์ได้ (Requirement 4)**
   - รองรับการอัปโหลดไฟล์ภาพจริง (`.png`, `.jpg`, `.jpeg`, `.webp`, `.svg`)
   - ระบบแสดงตัวอย่างรูปภาพแบบเรียลไทม์ (Live Image Preview) ก่อนกดบันทึก
   - แสดงรูปภาพขนาดจริงและ Thumbnail สวยงามในหน้ารายการคลัง, การขอยืม, และการจัดการอุปกรณ์

5. **ระบบออกเอกสารและรายงานพิมพ์จริง (Requirement 5)**
   - **ใบอนุญาตยืมวัสดุ/ครุภัณฑ์ (`/admin/borrowings/<id>/permit`)**: เอกสารอย่างเป็นทางการ พร้อมช่องเซ็นชื่อ 3 ตำแหน่ง (ผู้ยืม / ผู้อนุมัติ / ผู้บังคับบัญชา)
   - **ใบรับคืนวัสดุ/ครุภัณฑ์ (`/admin/returns/<id>/form`)**: เอกสารตรวจรับคืน พร้อมช่องเซ็นชื่อ 2 ตำแหน่ง (ผู้ส่งคืน / เจ้าหน้าที่ผู้รับคืน)
   - **รายงานสรุปรายเดือน (`/admin/reports/monthly`)**: ตารางยืม-คืน + ค่าปรับ พร้อมช่องเซ็นชื่อ 3 ตำแหน่ง กรองตามเดือน/ปีได้
   - **ทะเบียนครุภัณฑ์ (`/admin/reports/equipment-register`)**: รายการครุภัณฑ์ทั้งหมด + สถานะ กรองตามประเภทและสถานะได้ พร้อมช่องเซ็นชื่อรับรอง
   - ทุกเอกสารรองรับ **`window.print()`** — ซ่อน Sidebar/UI อัตโนมัติเมื่อพิมพ์ (`@media print`)
   - **Quick Print Panel** ในหน้า Dashboard เชื่อมทุกเอกสารไว้ในที่เดียว

6. **ระบบการสั่งซื้อวัสดุและครุภัณฑ์ใหม่ และจัดการข้อมูลบริษัทคู่ค้า (Requirement 6 - New!)**
   - **เมนูการสั่งซื้อพัสดุ/ครุภัณฑ์ (`/admin/purchases`)**: เข้าถึงได้จากแถบเมนูด้านซ้ายและ Dashboard
   - **ประวัติการสั่งซื้อ**: ดูรายการใบสั่งซื้อย้อนหลังทั้งหมด, ค้นหาตามเลขที่ PO หรือชื่อบริษัท, กรองตามสถานะ (รอรับพัสดุ / ตรวจรับแล้ว / ยกเลิก), พร้อมสรุปยอดสถิติการจัดซื้อ
   - **สร้างใบสั่งซื้อใหม่ (`/admin/purchases/new`)**:
     - **เลือกบริษัทคู่ค้า**: แสดงรายชื่อผู้จัดจำหน่าย และโชว์รายละเอียดผู้ติดต่อ เบอร์โทรศัพท์ ที่อยู่ เลขผู้เสียภาษี
     - **แสดงสินค้าที่บริษัทขาย (Supplier Catalog)**: เมื่อเลือกบริษัทแล้ว ระบบจะดึงรายการสินค้าที่บริษัทนั้นจำหน่ายขึ้นมาแสดงโดยอัตโนมัติ พร้อมปุ่ม `+ เพิ่ม` เพื่อนำลงในใบสั่งซื้อได้ในคลิกเดียว
     - **ค้นหาจากชื่อวัสดุและครุภัณฑ์ในระบบ**: ระบบค้นหาแบบเรียลไทม์ตามชื่อหรือรหัสพัสดุในคลัง เพื่อเลือกสั่งซื้อเพิ่มสต็อก
     - **สั่งจากรายการเดิม (Re-order)**: สามารถเลือกประวัติใบสั่งซื้อเดิมเพื่อคัดลอกรายการสินค้าทั้งหมดเข้ามาในใบสั่งซื้อใหม่ได้ทันที
   - **ดูและแก้ไขข้อมูลบริษัทคู่ค้า (`/admin/suppliers`)**:
     - ดูรายละเอียดบริษัทคู่ค้า ชื่อผู้ติดต่อ เบอร์โทร อีเมล เลขประจำตัวผู้เสียภาษี และที่อยู่
     - สามารถแก้ไขข้อมูลบริษัทได้ทั้งจากหน้าบริษัทคู่ค้า และแก้ไขได้ทันทีจากหน้าสร้างใบสั่งซื้อ / หน้ารายละเอียดใบสั่งซื้อ
     - สามารถเพิ่มและจัดการรายการสินค้าในแค็ตตาล็อกของบริษัทแต่ละแห่งได้
   - **การตรวจรับพัสดุเข้าคลังอัตโนมัติ**: เมื่อพัสดุมาส่ง สามารถกดบันทึกตรวจรับเข้าคลัง พร้อมตัวเลือกเพิ่มยอดสต็อกพัสดุคงเหลือในระบบโดยอัตโนมัติ

## 🚀 วิธีการติดตั้งและรันระบบ (How to Run)

1. ตรวจสอบไฟล์ในโฟลเดอร์โครงการ:
   ```bash
   cd "d:/ระบบยืม-คืน"
   ```

2. เริ่มต้นรันเซิร์ฟเวอร์ด้วยคำสั่ง:
   ```bash
   python app.py
   ```

3. เปิดเว็บเบราว์เซอร์ไปที่:
   ```
   http://127.0.0.1:5000
   ```
